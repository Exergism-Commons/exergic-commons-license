## Global license-fit consistency phase

The first global consistency audit is complete in `consistency/global-license-fit-audit.md`.

It found that the ECL 0.1 working text did not fully translate the repository's existing non-domination principle into operative language. `spec/PRINCIPLES.md` and the governance standard expressly addressed persecution, unlawful political repression, torture, collective punishment and arbitrary detention, while ECL 0.1 reached much of that conduct only through narrower surveillance, targeting, automated-discrimination or technological-capture formulations.

The root working `LICENSE` has therefore advanced to **ECL 0.2-DRAFT** without modifying the immutable `../../versions/licenses/ECL-0.1.md` snapshot. ECL 0.2-DRAFT adds a systematic-coercive-domination / unlawful-political-repression criterion, direct Schedule designation of exact Restricted Projects, an `Independent Remediation Activity` safe harbour and a more explicit designation/knowability rule.

No State tier has been changed merely because the draft language changed. The current `36 / 84 / 28 / 47` distribution remains provisional pending a **195-dossier delta audit against the exact ECL 0.2-DRAFT text**.
