## ECL 0.2 consistency phase — State delta complete

The first global consistency audit is in `consistency/global-license-fit-audit.md`. It found that ECL 0.1 under-expressed the non-domination rule already present in the repository principles/governance standard.

The root `LICENSE` therefore advanced to **ECL 0.2-DRAFT** without modifying the immutable `../../versions/licenses/ECL-0.1.md` snapshot. ECL 0.2-DRAFT adds a systematic-coercive-domination / unlawful-political-repression criterion, direct Schedule designation of exact Restricted Projects, an `Independent Remediation Activity` safe harbour and a more explicit designation/knowability rule.

The subsequent full State delta audit is recorded in `consistency/ecl-0.2-state-delta.md` and accounts for all 195 dossiers:

- 34 existing `R` upheld;
- **Israel `R → S`**;
- **United States `R → S`**;
- 83 existing `S` upheld without tier change;
- **Singapore `S` upheld but narrowed**, removing capital punishment/execution as a standalone ECL basis;
- all 28 `U` retained `U` after explicit 0.2 re-read; and
- all 47 `N` retained `N`.

The two `R → S` moves are scope corrections under the narrowest-accurate-attribution rule: materially independent judicial/audit/remedial functions make blanket whole-government classes overbroad even though serious qualifying coercive projects remain supported.

Singapore's correction implements the explicit ECL 0.2 guardrail that capital punishment, detention, deportation, conscription, protest regulation and comparable State powers are not standalone ECL categories; a qualifying project must independently satisfy an operative §5 criterion.
