# Global State Screening 2026 — DEPRECATED

> **Deprecated as an ECL decision framework.** This file is retained only to document an abandoned preliminary methodology.

The Exergic Commons License does **not** classify States according to Freedom House, V-Dem, geopolitical blocs, ideology, nationality, religion, or any other external ranking. Such sources may be cited inside an evidence dossier when relevant, but they are never ECL classification triggers and carry no privileged status.

The project now uses **195 individual State evidence dossiers**, one for each of the 193 UN Member States plus the State of Palestine and the Holy See.

See [`STATE-DOSSIERS.md`](STATE-DOSSIERS.md) for the canonical index and issue **#1** for the common ECL-native review schema.

Each dossier must independently examine:

- internal human agency and meaningful contestability;
- expression, association, research and dissent;
- arbitrary detention, torture, disappearance and coercive punishment;
- surveillance, censorship and information control;
- discriminatory domination and forced assimilation;
- due process, reversibility and meaningful exit;
- institutional capture and concentration of coercive capacity;
- external targeting, occupation, annexation and denial of self-determination;
- rendition, secret detention and transnational repression;
- material support for other ECL-prohibited projects;
- institutional attribution and persistence;
- primary or authoritative evidence;
- credible contrary evidence and uncertainty; and
- reviewability of any conclusion.

Possible reasoned outcomes are **No current state-level basis**, **Restricted with defined scope**, **State apparatus Restricted**, or **Under Review / insufficient evidence**.

A dossier has no licensing effect by itself. Only the exact `RESTRICTED-PARTIES.md` Schedule incorporated by a software release can create an operative ECL restriction.

Historical versions of this file remain available through Git history for transparency.
