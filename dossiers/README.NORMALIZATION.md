# Dossier normalization status

State dossiers are being normalized from the 2026 adjudication and adversarial-review records into the canonical schema in `dossiers/states/_TEMPLATE.md`.

A normalized dossier is self-contained enough to explain its current governance outcome, scope, supporting evidence, counter-evidence, attribution, adversarial result, review/removal triggers and principal sources without requiring the reader to reconstruct the result from historical tranche files.

Historical review records remain authoritative procedural history but are not the canonical current State entry point.

This migration changes governance documentation only. It does not alter `LICENSE` or any operative Restricted Parties Schedule.
