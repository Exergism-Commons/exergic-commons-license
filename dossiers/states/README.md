# State dossiers

This directory contains one canonical entry point for each of the 193 UN Member States plus the State of Palestine and the Holy See: **195 / 195**.

The 2026 migration preserves the detailed first-pass evidence and adversarial reasoning in `../../reviews/2026/`. Each State file records its current provisional governance outcome and links to that evidence trail. Future evidence and determinations should be normalized into the per-State file rather than added as new root-level research documents.

Outcome codes are defined in `../../spec/TERMINOLOGY.md`.

No State dossier creates licensing effect by itself.
