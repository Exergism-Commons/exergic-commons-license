# Example State

> **Governance record only.** This dossier does not itself create licensing restrictions. Only a versioned Schedule expressly incorporated by a software release has operative effect.

## 1. Current determination

State the current ECL outcome (`R`, `S`, `U`, or `N`), exact institutional/project scope, and confidence.

## 2. Formal Exergism assessment

Link the machine-readable assessment under `../../exergism/assessments/` and state whether the exact object is `scorable`, `insufficient_evidence`, or `not_applicable` under `../../spec/EXERGIC-ANALYSIS.md`.

Where scorable, summarize the evidence-backed intervals for `P`, `A`, `V_ep`, `L`, `O`, `U`, `C`, `S`, `R`, `Ecol`, and `D_p`; identify the parameter profile(s); report `Ex_b`, `Ex_r`, `E_i`, `X_h`, `B_0`, and `N_t` where data permit; and explain sensitivity or disagreement.

Never infer an ECL tier mechanically from a formal score. Never assign midpoint values merely because evidence is missing.

## 3. ECL criteria engaged

Identify the relevant ECL criteria: repressive surveillance, political repression, coercive targeting/unlawful violence, systematic discriminatory domination, deceptive manipulation, irreversible coercive capture, or circumvention.

Explain whether the formal Exergism result actually supports the causal theory behind the exact operative criterion or exposes a mismatch.

## 4. Evidence supporting the determination

Record the material facts and attribution. Prefer primary/authoritative sources and distinguish findings, allegations, and inference.

## 5. Counter-evidence and exergic institutions

Record courts, ombuds institutions, auditors, prosecutors, reforms, releases, remediation, or other evidence tending to narrow or defeat restriction. Where supported, explain how these affect autonomy, truth access, liberation, openness, capture, or relapse risk in the formal analysis.

## 6. Attribution and exclusions

Explain exactly which institutions/projects are covered and which are excluded. Never extend a State finding to its population or nationality.

The object scored in the formal Exergism assessment must match this attribution or be explicitly narrower.

## 7. Adversarial determination

Record whether review UPHELD, NARROWED, DOWNGRADED, or REMOVED the prior finding and why. Include any material disagreement between the formal Exergism layer and the legal/governance determination.

## 8. Review / removal triggers

List objective developments that should force renewed review or justify narrowing/removal. Where possible, identify which formal variables should change if remediation is real.

## 9. Sources

Use stable source URLs where possible.

## 10. Procedural history

Link the original issue, initial adjudication, formal Exergism assessment, adversarial-review tranche, and any later challenge/removal proceedings.
