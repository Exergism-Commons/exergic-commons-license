# Project dossiers

Project- and program-specific evidence belongs here, including military targeting programs, surveillance deployments, detention systems and other defined projects. Use [`_TEMPLATE.md`](_TEMPLATE.md).

Under **ECL 0.2-DRAFT**, an exact incorporated Schedule may independently designate a named project as a Restricted Project. Project dossiers therefore require unusually clear boundaries: operator, timeframe, contract/program identifiers, technical/operational scope and material participants.

## Outcomes

- **`R` — Restricted Project candidate:** the exact project/deployment itself satisfies an operative ECL criterion.
- **`S` — Scoped project candidate:** only a defined phase, function, component or deployment qualifies.
- **`U` — Under Review:** the project is sensitive or implicated but causation, deployment, prohibited-use fit, attribution or counter-evidence prevents stable restriction.
- **`N` — No current project-level basis.**

A dual-use system, military system, immigration system, detention system or surveillance capability is not automatically Restricted. The actual project must materially satisfy an ECL prohibited-use criterion.

Material participation in a Restricted Project can affect suppliers/contractors under the operative Covered Associate / project rules without converting every other activity of the supplier into a Restricted Party.
